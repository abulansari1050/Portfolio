# MD Abul Ansari Portfolio

## Files
- index.html
- style.css
- script.js
- resume.pdf (replace the placeholder with your PDF resume)

## GitHub Pages
1. Create a public repository named `abulansari.github.io` (or your preferred repo).
2. Upload index.html, style.css, script.js and resume.pdf.
3. Open Settings -> Pages.
4. Select Deploy from branch -> main -> / (root).
5. Save and wait for deployment.
6. Your site will be available at the GitHub Pages URL shown by GitHub.

## Important
The HTML currently uses `resume.pdf` for the Download Resume button. Export your resume DOCX as PDF, name it `resume.pdf`, and place it beside index.html before deploying.
